# Modelos e Templates

Repositório criado para armazenar arquivos padronizados, modelos e templates utilizados na organização Senac Montenegro.

Conteúdos:

- Modelos de documentos  
- Templates de apresentações  
- Formulários  
- Checklists  
- Materiais de uso comum

Facilita a padronização e a uniformidade dos materiais produzidos pelos alunos e docentes.
